## ❓ FAQ

### Do I need to run it as Administrator?

No. This repository is an informational reference and does not contain software that needs to be launched.

### Does this repository include an automated Hearthstone bot?

No. It contains reference material only and does not provide software that plays matches or performs in-game actions.

### Are Hearthstone bots allowed?

Blizzard's End User License Agreement prohibits unauthorized software that automates control of a game. Review the current agreement before using third-party tools.

### Can botting result in an account ban?

Yes. Blizzard has publicly announced enforcement actions against accounts using programs that automate Hearthstone gameplay. Penalties can include account closure.

### Is a deck tracker the same as a bot?

No. A passive deck tracker observes game information, while a bot automates gameplay actions. Check the tool's behavior and applicable Blizzard rules rather than relying only on its name.
